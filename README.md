# True North Dental Care: Digital Marketing Strategy & Launch Proposal

Interactive proposal prepared by Generate Your Audience (GYA) for True North Dental Care, 8 Mount Koolmoon Street, Smithfield QLD.

## Publish on GitHub Pages
1. Create a new repository and upload everything in this folder (index.html, .nojekyll, og-image.png, favicons, README.md).
2. Settings > Pages > Deploy from a branch > main / (root) > Save.
3. In index.html, replace `YOUR-USERNAME` and `REPO-NAME` (4 places, marked with a comment) with the live Pages URL so link previews show the og-image.

## Notes
- Self-contained: charts (Chart.js) and the map engine (Leaflet) are embedded. Map tiles and Google Fonts load online.
- The page carries `noindex, nofollow` so search engines will not list it. Note a public repository is still visible on GitHub itself, so use a private repo with Pages, or host on the GYA reporting domain, if the content should stay private.
